BridgeWork is a modern web platform designed to streamline job posting and matching. By providing an intuitive interface for both job seekers and employers, the platform bridges the gap to find the perfect fit.

## 🚀 Features

- **User Registration & Authentication**: Secure sign up for users.
- **Job Posting System**: Employers can easily post and manage job listings.
- **Intelligent Matching (`/match`)**: Algorithms to connect candidates to the right opportunities.
- **Interactive Dashboard**: Track your applications, job postings, and profile matching status.
- **Responsive Design**: Polished UI built with Tailwind CSS, ensuring a great experience on mobile and desktop devices.

## 🛠️ Technology Stack

- **Frontend Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite 8](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Routing**: [React Router v7](https://reactrouter.com/)
- **Linting**: [ESLint](https://eslint.org/)

## 💻 Getting Started

### Prerequisites

Ensure you have the following installed on your local machine:
- [Node.js](https://nodejs.org/) (LTS recommended)
- `npm` (comes with Node.js)

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/abeyakilesh/WorkBridge.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd "Bridge Work 2.0"
   cd bridgework-app
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **View the application:**
   Open your browser and navigate to `http://localhost:5173` (or the port specified in your terminal).
